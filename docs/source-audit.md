## How these were likely produced

One cited source is:

    https://www.nursingcouncil.org.nz/IQN/Competence_Assessment/English_Language_Requirements/NCNZ/IQN/English_Language_Requirements.aspx

That path repeats `IQN` and `English_Language_Requirements` twice. It is not a URL that was
visited and copied; it is one that was assembled. Combined with the fabricated reviewer and
the invented contributor testimonials, the safe assumption is that no citation on this site
has been opened by a human. Treat every one as unverified until someone does.
